# FreightIQ

FreightIQ is a maritime and air freight intelligence platform that makes global shipping data understandable for logistics students, junior professionals, and small importing/exporting businesses.

## Features

- **Real-time Freight Indices**: Track Baltic Dry Index, Container rates, Air freight indices
- **Global Routes Database**: Monitor 15+ maritime and air routes with live pricing
- **Port Intelligence**: Real-time port congestion monitoring across 8 major ports
- **Market Events**: Stay updated on geopolitical, seasonal, and operational impacts
- **Learning Hub**: Educational content for logistics beginners
- **Price Alerts**: Custom notifications for route price changes
- **Freemium Model**: Free tier with premium and professional tiers

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **State Management**: Zustand
- **Authentication**: NextAuth.js
- **Icons**: Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
